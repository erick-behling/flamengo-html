<h1> Site do Flamengo </h1>
<p> Um site fictício do Flamengo criado em sala de aula na disciplina de Programação de Aplicativos. </p>
<h2> Sobre o site</h2>
<p> O site apresenta a história e as conquistas do Flamengo até 2025 e, logo depois, apresenta uma página de cadastro e contato fictício sobre uma escolinha. </p>
<h2> Objetivo educacional</h2>
<p> O intuito da atividade estudar e aprender HTML.
